ARTESCA OBJECT MANAGEMENT
OFFLINE RUN INSTRUCTIONS

FIRST TIME ONLY:

1. Open terminal.

2. Go to project:

   cd ~/projects/artesca-object-management

3. Make scripts executable:

   chmod +x setup_offline.sh start_all.sh stop_all.sh

4. Run setup:

   ./setup_offline.sh


FOR EVERY DEMO:

1. Open terminal.

2. Go to project:

   cd ~/projects/artesca-object-management

3. Start:

   ./start_all.sh

4. Open browser:

   http://127.0.0.1:5173


TO STOP:

   ./stop_all.sh
